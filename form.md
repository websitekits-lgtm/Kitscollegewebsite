Create a **College Admission Form** with the following sections and fields exactly as listed below.

## 1. Personal Details

Include the following fields:

* Student First Name *(Required)*
* Student Last Name (As per Aadhaar) *(Required)*
* Father / Guardian Name *(Required)*
* Mother Name
* Date of Birth
* Gender

  * Male
  * Female
  * Other
* Mobile Number *(Required)*
* Email ID
* Aadhaar Number
* Nationality (Default: Indian)
* Religion
* Category
* Blood Group
* Are you Physically Challenged?

  * Yes
  * No
* Alternate Mobile Number

---

## 2. Address Details

Include the following fields:

* Address (House No. / Street)
* Landmark (Optional)
* City / Village
* District
* State
* Pincode
* Country (Default: India)

---

## 3. Choose the Program

Include the following fields:

* Program Type (Dropdown)
* Program / Course (Dropdown)

---

## 4. Other Details

Include the following questions:

* Do you require Hostel Facility?

  * Yes
  * No

* Do you require Transport Facility?

  * Yes
  * No

---

## 5. Declaration

Include a mandatory declaration checkbox with the following text:

> I hereby declare that the information provided above is true and correct to the best of my knowledge and belief. I understand that any false information may lead to cancellation of my admission.

---

## Buttons

* Submit Application
* Reset

---

The form should maintain the same section order, field names, and logical grouping as a standard college admission form, ensuring all required student personal information, address details, program selection, facility preferences, and declaration are collected before allowing submission.
